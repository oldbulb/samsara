A harness that improves itself, under evidence it cannot fake. 让 harness 自己改进自己——在它伪造不了的证据下。

samsara is the self-improvement substrate for agent harnesses: it lets a running harness keep iterating on itself under evidence that comes from reality, is not contaminated by the optimizer, and can be retroactively overturned.

samsara 是 agent harness 的自改进基座：让一个运行中的 harness 在来自现实的、 未被优化器污染的、可追溯推翻的证据下，持续迭代自己。

Each change is a challenger, evaluated in a disposable sub-scope. It becomes the champion only by passing a statistical gate on truth from outside the loop, and only after a human signs off through a channel the loop cannot reach. What is improved is the harness, not the weights.

每个改动是一个 challenger，在可处置的子 scope 里求值；只有凭回路之外的真值通过统计门， 并由人经回路够不到的通道签字，才成为 champion。改的是 harness，不是权重。

The loop回路

One loop, three fixed points 一个回路，三个不动点

The cycle is propose → run → judge → keep-or-drop → settle. Three things sit outside it and cannot be written from inside: the book (tasks and truth), the gate (verdicts), and sign-off (a human). Everything else — the optimizer included — can be improved.

循环是 propose → run → judge → keep-or-drop → settle。三样东西在回路之外、回路内写不到： book（任务与真值）、gate（裁决）、sign-off（人）。 其余的一切——包括 optimizer 自己——都可以被改进。

book

From reality来自现实

Truth lives outside the loop. It arrives immediately or late; settlement is an event that re-scores the ancestry, append-only.

真值在回路之外。它即时到达或延迟到达；settlement 是一个事件，沿祖先重打分，只追加不覆盖。

gate

Not contaminated未被污染

The holdout is a consumable and its revelations are budgeted. The judge is isolated by machinery, not convention; judge-kind scores never reach a verdict.

holdout 是消耗品，对它的每次揭示都记账。裁判由机器隔离，不靠约定；judge 类分数永远进不了 verdict。

sign-off

Overturnable可推翻

Every adoption carries full coordinates. Consent is an Ed25519 signature over a local socket — a sandbox cannot forge it, and HTTP is not proof.

每次采纳都带完整坐标。签字是本地 socket 上的 Ed25519 签名——沙箱伪造不了，HTTP 不算证明。

What changes改什么

Surfaces, not weightssurface，不是权重

A harness is everything mutable around the model. Each mutable layer is a surface; a challenger is the champion plus one patch on one surface — without that constraint, improvement cannot be attributed.

harness 是模型周围一切可变的东西。每个可变层是一个 surface；一个 challenger = champion 加上 单个 surface 上的一个补丁——不这样约束，改进就无法归因。

Where it intends to lead要领先的地方

Three things nobody has built yet三件还没人做过的事

Stated with the prior art named honestly — the theory exists in every case; the engineering does not.

先例照实点名——三件事的理论都已存在，工程实现没有。

  1. Holdout accounting. Recursive reuse of a holdout across generations learns it away. samsara budgets holdout revelations (Thresholdout / Ladder — Dwork et al. 2015, Blum & Hardt 2015), declares n / mde / budget per pack, fails fast when the holdout cannot support the round, and rotates from newly settled tasks when the budget is spent. No agent-optimization system does this today. holdout 记账。跨代递归复用 holdout 会把它学掉。samsara 给每次揭示记账 （Thresholdout / Ladder——Dwork et al. 2015、Blum & Hardt 2015），每个 pack 声明 n / mde / budget，holdout 撑不起这一轮就当场失败，预算耗尽则从新结算的任务里轮换。 目前没有任何 agent 优化系统这样做。
  2. An automated loop on delayed truth. Every RSI and skill-optimization system evaluates on immediate benchmarks. Tasks whose truth arrives next month can still drive the loop here — the step from RSI-on-benchmarks to RSI-in-production. 延迟真值上的自动回路。现有的自改进与 skill 优化系统都在即时 benchmark 上评测。 真值下个月才到的任务在这里照样能驱动回路——这是从「benchmark 上的 RSI」走向「生产中的 RSI」的一步。
  3. A living champion. A truth revision, a scorer bump, a model upgrade or a task-set change is an event: it re-scores the ancestry append-only and can demote the champion. Existing tools offer manual, per-run back-fill; the automatic trigger is new. 活的 champion。真值修订、scorer 升版、模型升级、任务集变更都是事件： 沿祖先追加式重打分，并且可以把 champion 降级。现有工具只提供手动的、逐次运行的回填；自动触发是新的。

How a round runs一轮怎么跑

One command, one verdict, one ledger row一条命令，一个裁决，一行账

A proposer (an external CLI) writes a patch; the runner scopes it, runs the attempts on a loop provider, scores them against the pack's own truth command, and asks the gate. Promotion additionally requires a signature.

proposer（一个外部 CLI）产出补丁；runner 给它开 scope、在 loop provider 上跑 attempt、用 pack 自己的 truth 命令打分，然后问 gate。晋升还需要一个签名。 

# propose → challenge → attempts → gate → ledger, in one round
dsh --profile host round \
    --pack packs/coding-tasks --loop dsh --proposer claude-p \
    --set smoke --limit 2 --metric pass_rate --with-champion

# promotion waits for a signature over a unix socket; HTTP is not proof
dsh --profile host promote <challengerId> --wait 60

Status现状

What is built, and what is honestly not做完了什么，什么老实说还没有

Built已完成

  • 18 packages: kernel, book, pack, ledger, scope, champion, gate, signoff, loops (+ dsh and Claude Code providers), workdir, submit, proposers, sandbox, runner, ui.18 个包：kernel、book、pack、ledger、scope、champion、gate、signoff、loops（含 dsh 与 Claude Code 两个 provider）、workdir、submit、proposers、sandbox、runner、ui。
  • Two harnesses run the same tasks and certify against each other; A/B is refused when their facts differ.两个 harness 跑同一批任务并互相认证；facts 不同的两行拒绝 A/B 比较。
  • Append-only ledger on sqlite; disposable scopes; Ed25519 sign-off; hot-apply verified by re-hashing.sqlite 上的追加式 ledger；可处置 scope；Ed25519 签字；热应用靠重新哈希验证。
  • 39 test files / 270 tests, all offline — no model, no network.39 个测试文件 / 270 个测试，全部离线——不调模型、不联网。

Not yet还没有

  • The task set is at ceiling for the model under test, so the noise floor is zero and no positive control has promoted yet. The statistical gate has not been falsified against a known-good change.当前任务集对被测模型来说在天花板上，噪声底为零，阳性对照还没有晋升过。统计门还没有被一个已知有效的改动真正证伪过。
  • The live tier (mSPRT) is not implemented.live tier（mSPRT）未实现。
  • The proposer process has no filesystem sandbox yet; diff scanning and the gate are the current mitigations.proposer 进程还没有文件系统沙箱；目前靠 diff 扫描与 gate 兜底。

Not released yet. The repository is public so the design can be read and argued with, but there is no package, no versioned API and no support. Interfaces will change without notice.

尚未发布。仓库公开是为了让设计可读、可被质疑；没有发包、没有稳定 API、没有支持。 接口会不打招呼地变。
