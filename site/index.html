A harness that improves itself, under evidence it cannot fake. 让 harness 自己改进自己——在它伪造不了的证据下。

samsara is the self-improvement substrate for agent harnesses: it lets a running harness keep iterating on itself under evidence that comes from reality, is not contaminated by the optimizer, and can be retroactively overturned.

samsara 是 agent harness 的自改进基座：让一个运行中的 harness 在来自现实的、 未被优化器污染的、可追溯推翻的证据下，持续迭代自己。

Each change is a challenger, evaluated in a disposable sub-scope. It becomes the champion only by passing a statistical gate on truth from outside the loop, and only after a human signs off through a channel the loop cannot reach. What is improved is the harness, not the weights.

每个改动是一个 challenger，在可处置的子 scope 里求值；只有凭回路之外的真值通过统计门， 并由人经回路够不到的通道签字，才成为 champion。改的是 harness，不是权重。

It is also the bench: any optimizer is a proposer, any accept rule is a gate — both in any language — and all of them are judged on one ledger against one measured noise floor. Other people's optimizers are our positive controls.

它同时是评测台：任何优化器都是 proposer，任何接受准则都是 gate——都可以用任意语言写—— 全部在同一个 ledger、同一个实测噪声底上被裁决。别人的优化器就是我们的正面对照。

The loop回路

One loop, three fixed points 一个回路，三个不动点

The cycle is propose → run → judge → keep-or-drop → settle. Three things sit outside it and cannot be written from inside: the book (tasks and truth), the gate (verdicts), and sign-off (a human). Everything else — the optimizer included — can be improved.

循环是 propose → run → judge → keep-or-drop → settle。三样东西在回路之外、回路内写不到： book（任务与真值）、gate（裁决）、sign-off（人）。 其余的一切——包括 optimizer 自己——都可以被改进。

book

From reality来自现实

Truth lives outside the loop. It arrives immediately or late; settlement is an event that re-scores the ancestry, append-only.

真值在回路之外。它即时到达或延迟到达；settlement 是一个事件，沿祖先重打分，只追加不覆盖。

gate

Not contaminated未被污染

The holdout is a consumable and its revelations are budgeted. The judge is isolated by machinery, not convention; judge-kind scores never reach a verdict.

holdout 是消耗品，对它的每次揭示都记账。裁判由机器隔离，不靠约定；judge 类分数永远进不了 verdict。

sign-off

Overturnable可推翻

Every adoption carries full coordinates. Consent is an Ed25519 signature over a local socket — a sandbox cannot forge it, and HTTP is not proof.

每次采纳都带完整坐标。签字是本地 socket 上的 Ed25519 签名——沙箱伪造不了，HTTP 不算证明。

What changes改什么

Surfaces, not weightssurface，不是权重

A harness is everything mutable around the model. Each mutable layer is a surface; a challenger is the champion plus one patch on one surface — without that constraint, improvement cannot be attributed.

harness 是模型周围一切可变的东西。每个可变层是一个 surface；一个 challenger = champion 加上 单个 surface 上的一个补丁——不这样约束，改进就无法归因。

What it contributes它贡献什么

The record, the arena, and truth that arrives late记录、竞技场，和迟到的真值

Stated against the 2026 literature, with the prior art named and the limits attached.

对照 2026 年的文献来说，先例照实点名，边界一并附上。

  1. The record. Five 2026 systems report a self-improvement run five incompatible ways, so no two runs can be compared — which is why nobody ever audited the field's most-cited curve. samsara's ledger row carries the lineage, the one surface touched, paired per-task scores, the measured noise floor, the gate and its parameters, cost, settlements and append-only re-scores; its spine is a coordinate tuple, and comparable is a rule the gate checks, not a convention. 记录。2026 年五个系统用五种互不相容的口径报告自改进运行，两次运行无法比较—— 这就是为什么没人审计过这个领域被引最多的那条曲线。samsara 的 ledger 行带谱系、碰的那一个 surface、 成对逐题分数、实测噪声底、gate 及参数、成本、settlement 与只追加的重打分；它的脊梁是坐标元组， "可比"是 gate 检查的规则，不是约定。
  2. The arena. Every published accept rule is a plugin, not a rival: thirteen ship in gate-catalog — keep-better, DGM, Self-Harness, RSEA, Ladder, Miller, McNemar, PACE, HCL, AutoScientists, gate-default — and gate bench runs any of them, or yours, on recorded reruns of one configuration, where every acceptance is a false one. On our data: keep-better 0.51, DGM 0.72–1.00, Ladder 0.12–0.20, gate-default 0.06 against a declared 0.05, Miller 0.04. 竞技场。每一条已发表的接受准则都是插件而不是对手：gate-catalog 带了十三条—— keep-better、DGM、Self-Harness、RSEA、Ladder、Miller、McNemar、PACE、HCL、AutoScientists、gate-default—— gate bench 能把其中任何一条、或你写的一条，跑在"同一配置的重跑"上，那里每次接受都是假阳性。 我们的数据上：keep-better 0.51、DGM 0.72–1.00、Ladder 0.12–0.20、gate-default 0.06（声明 0.05）、Miller 0.04。
  3. Truth that arrives late — built, unexercised. Every benchmark in the field verifies immediately. Here a book declares truth latency, settlement is an event, and a revision re-scores the ancestry append-only and can demote the champion. No pack in tree drives it yet; it is written here as a direction with dormant machinery, not a demonstrated capability. 迟到的真值——已建成，未驱动。这个领域的每个 benchmark 都即时验证。这里 book 声明真值延迟， settlement 是事件，一次修订沿祖先追加式重打分并可降级 champion。树内还没有 pack 驱动它；它在这里是 一个方向加一套休眠的机器，不是演示过的能力。

Not claimed: holdout accounting (engineering, not a lead — Thresholdout is infeasible at this scale), sequential testing (Statsig, Eppo, PACE), retention (HCL's; adopted as a calibrated bound).

不声称的：holdout 记账（是工程不是领先——Thresholdout 在这个规模不可行）、序贯检验（Statsig、Eppo、PACE）、 保留规则（HCL 的；我们以校准的上界形式采纳）。

How a round runs一轮怎么跑

One command, one verdict, one ledger row一条命令，一个裁决，一行账

A proposer (an external CLI) writes a patch; the runner scopes it, runs the attempts on a loop provider, scores them against the pack's own truth command, and asks the gate. Promotion additionally requires a signature.

proposer（一个外部 CLI）产出补丁；runner 给它开 scope、在 loop provider 上跑 attempt、用 pack 自己的 truth 命令打分，然后问 gate。晋升还需要一个签名。 

# propose → challenge → attempts → gate → ledger, in one round
dsh --profile host round \
    --pack packs/coding-tasks --loop dsh --proposer claude-p \
    --set smoke --limit 2 --metric pass_rate --with-champion

# promotion waits for a signature over a unix socket; HTTP is not proof
dsh --profile host promote <challengerId> --wait 60

Plug in接入

Your gate, your optimizer — in any language, in an afternoon你的 gate、你的优化器——任意语言，一个下午

A gate is a program: a compare request on stdin, a verdict on stdout. A proposer is a program: a view directory in, a proposal directory out. SDKs in TypeScript and Python; a zero-spend dry run; a bench that tells you your rule's false-promote rate on real reruns before you trust it.

gate 是一个程序：stdin 读比较请求，stdout 写裁决。proposer 是一个程序：读一个 view 目录，写一个提案目录。 TypeScript 与 Python 两份 SDK；零花费的 dry run；一个 bench，在你信任你的规则之前先告诉你它在真实重跑上的假晋升率。 

# a gate in stdlib Python (examples/gates/keep_better.py), measured against the catalog
dsh --profile host gate bench --attempts data/runs/noise/attempts.jsonl \
    --tasks packs/coding-tasks/tasks/holdin.jsonl --metric pass_rate \
    --gates default,keep-better,pace,miller --gate-command ./my_gate.py

# an optimizer in Python (sdk/py), run against the champion's view — no scope, no attempt, no spend
dsh --profile host propose --pack packs/coding-tasks --proposer ./my_optimizer.py \
    --set holdin --limit 8 --metric pass_rate --dry-run

Status现状

What is built, and what is honestly not做完了什么，什么老实说还没有

Built已完成

  • 20 packages: kernel, book, pack, ledger, scope, champion, gate, gate-catalog, signoff, loops (+ dsh and Claude Code providers), workdir, submit, proposers, proposer-sdk, sandbox, runner, ui — plus a Python proposer SDK and stdlib examples.20 个包：kernel、book、pack、ledger、scope、champion、gate、gate-catalog、signoff、loops（含 dsh 与 Claude Code 两个 provider）、workdir、submit、proposers、proposer-sdk、sandbox、runner、ui——外加 Python 的 proposer SDK 与纯标准库范例。
  • A measured noise floor (83 tasks × 3 reruns, closed-book) and a gate calibrated on it: 0.06 false-promote against a declared 0.05, 0 of 6 real rerun pairs.实测噪声底（83 题 × 3 次重跑，closed-book）和在其上校准过的 gate：假晋升率 0.06（声明 0.05），6 对真实重跑上 0/6。
  • Two harnesses run the same tasks and certify against each other; A/B is refused when their facts differ.两个 harness 跑同一批任务并互相认证；facts 不同的两行拒绝 A/B 比较。
  • Append-only ledger on sqlite; disposable scopes; Ed25519 sign-off; hot-apply verified by re-hashing.sqlite 上的追加式 ledger；可处置 scope；Ed25519 签字；热应用靠重新哈希验证。
  • 47 test files / 344 tests, all offline — no model, no network.47 个测试文件 / 344 个测试，全部离线——不调模型、不联网。

Not yet还没有

  • The gate has never promoted anything. The effect this pack can detect (≈0.14 at 3 reruns) is above the SESOI it declares (0.05), so every real comparison ends hold:underpowered — right in kind, unfalsified in fact. At the held-out tier's 29 entities the bootstrap runs ≈1.5× nominal.gate 从未晋升过任何东西。这个 pack 能检出的效应（3 次重跑约 0.14）高于它声明的 SESOI（0.05），每次真实比较都以 hold:underpowered 结束——性质上对，事实上未被证伪。held-out tier 的 29 个 entity 上 bootstrap 约为标称的 1.5 倍。
  • The pack's truth is partly self-graded: agent-written tests are counted alongside the hidden ones (open bug; solved is unaffected).pack 的真值部分自评：agent 自己写的测试和隐藏测试一起计数（未修；solved 不受影响）。
  • The live tier (mSPRT) is not implemented.live tier（mSPRT）未实现。
  • The proposer process has no filesystem sandbox yet; diff scanning and the gate are the current mitigations.proposer 进程还没有文件系统沙箱；目前靠 diff 扫描与 gate 兜底。

Not released yet. The repository is public so the design can be read and argued with, but there is no package, no versioned API and no support. Interfaces will change without notice.

尚未发布。仓库公开是为了让设计可读、可被质疑；没有发包、没有稳定 API、没有支持。 接口会不打招呼地变。

Where this goes. The next consumer is a place, not a pack: dsh as the workbench on which RSI experiments are run — you talk to dsh, the agent drives samsara through tools, the conversation is the notebook, /samsara commands are the only place consent happens, the ledger is the record.

走向。下一个消费者是一个地方，不是一个 pack：把 dsh 变成跑 RSI 实验的台子——你跟 dsh 说话， agent 经工具驱动 samsara，对话就是笔记本，/samsara 命令是签字唯一发生的地方，ledger 是记录。
