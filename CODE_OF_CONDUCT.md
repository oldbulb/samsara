# Code of conduct

## The short version

Be decent. Argue with the work, not the person. Assume the other side is trying
to get it right.

## What that means here

- Technical disagreement is welcome and expected; personal attacks, harassment,
  demeaning comments and unwelcome attention are not.
- Critique claims, code and reasoning. "This benchmark does not support that
  conclusion" is the kind of comment this project exists for. "You are an idiot"
  is not.
- Do not derail threads, publish others' private information, or use the issue
  tracker to pursue people.
- If you are wrong, say so and move on. Nobody is keeping score.

## Scope

This applies in the repository — issues, pull requests, discussions, commit
messages, code and documentation — and anywhere someone represents the project.

## If something goes wrong

Report it privately through GitHub's private vulnerability reporting on this
repository, or contact the maintainer at the address on their GitHub profile.
Reports are handled privately. The maintainer may edit or delete comments, close
threads, or block accounts, and will say when they have.

This project is small; there is no committee. What there is, is a maintainer who
would rather lose a contributor than keep a hostile one.

If you want the fuller, more formal treatment of the same ideas, the
[Contributor Covenant](https://www.contributor-covenant.org/) is the standard
reference.
